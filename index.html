Metodología

Teoría, práctica y proyectos reales

Cada módulo combina exposición teórica-visual, diagramación interactiva, live coding y laboratorios prácticos para que domines HTML, CSS y JavaScript con bases profesionales.

Enfoque 1

Fundamentos sólidos

Comprende cómo funciona la web: protocolos HTTP, arquitectura cliente-servidor, HTML semántico, CSS moderno y JavaScript ES6+.

  • Live coding en cada módulo
  • Diagramas con Excalidraw
  • Quizzes y mapas conceptuales
Enfoque 2

Proyectos de portafolio

Construye aplicaciones interactivas reales: contador, reloj digital, to-do list, modo oscuro/claro y tu proyecto final integrador.

  • Laboratorios guiados paso a paso
  • Consumo de APIs con fetch
  • Despliegue en producción con Git
